# PinjamKampus — Sistem Peminjaman Alat & Lab Kampus

Aplikasi web interaktif untuk mempermudah mahasiswa dalam mengecek ketersediaan inventaris serta mengajukan peminjaman alat dan fasilitas laboratorium di lingkungan kampus secara online.

## 🚀 Fitur Utama
- **Katalog Inventaris**: Menampilkan daftar alat dan ruang lab yang tersedia.
- **Interaktif & Dinamis**: Menampilkan detail informasi alat/ruang lab secara dinamis tanpa reload halaman menggunakan JavaScript DOM Manipulation.
- **Tampilan Responsif**: Menggunakan Tailwind CSS agar nyaman diakses dari smartphone maupun laptop.

## 🛠 Teknologi yang Digunakan
- **HTML5** — Struktur konten web
- **Tailwind CSS (CDN)** — Styling & layout responsif
- **JavaScript (ES6)** — DOM Selection, Event Handling, dan Manipulasi Elemen
